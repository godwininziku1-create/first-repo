# Africa Youth Hope Alive — Website

This is a lightweight static website scaffold for the Africa Youth Hope Alive Project. It uses a clean, eco-conscious design and placeholder imagery for now.

Files created:

- [index.html](index.html#L1) — Homepage with mission, values and program previews (hero slider)
- [programs.html](programs.html#L1) — Programs listing (hero)
- [mentorship.html](mentorship.html#L1) — Mentorship Series details
- [digi-girls.html](digi-girls.html#L1) — Digi Girls curriculum
- [tree-planting.html](tree-planting.html#L1) — Tree planting campaigns
- [sustainable-agriculture.html](sustainable-agriculture.html#L1) — Sustainable agriculture training
- [multimedia.html](multimedia.html#L1) — Multimedia & storytelling
- [about.html](about.html#L1) — Background and approach (hero)
- [about.html#team](about.html#L1) — Team and volunteer info (placeholder avatars + socials)
- [donate.html](donate.html#L1) — Ways to support (placeholder)
- [index.html#faq](index.html#L1) — Frequently asked questions
- [resources.html](resources.html#L1) — Program toolkits and resources
- [contact.html](contact.html#L1) — Contact and outreach (hero)
- [css/styles.css](css/styles.css#L1) — Main stylesheet (hero, footer, team, socials)
- [js/main.js](js/main.js#L1) — Interaction scripts (nav, modal, slider, share, newsletter)


To view locally, open `index.html` in a browser or run a simple static server. Example with Python 3:

```bash
python -m http.server 8000
# then open http://localhost:8000
```
